# Palette comparison images

Ten labeled PNG layouts exported from the palette presentation. Each contains aligned Unfiltered, Deuteranopia, Protanopia, and approximate Tritanomaly captures.

Use `balanced.png` for the four-view compromise and `matched-y-cues.png` for the additional shape identifier. The source RGB and numerical screening scores appear on each layout. Original Unity captures remain in `../palette-lab-20261021/`.

The former ZIP duplicated the repository's presentation, raw images, viewer, and data. These individual layouts preserve its unique image exports. See [the study note](../../research/palette-lab.md) for methods and limitations.
